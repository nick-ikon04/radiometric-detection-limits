# Межі виявлення в радіометрії

[English version](README.md)

Навчальний Python-проєкт для розрахунку порога прийняття рішення, межі
виявлення, довірчих інтервалів, активності та питомої активності за результатами
радіометричних вимірювань. Також реалізовано оброблення піка гамма-спектра за
допомогою області інтересу (ROI) та двох бічних фонових ділянок.

## Що демонструє проєкт

- розрахунок фонової, брутто- та нетто-швидкості лічби;
- поріг прийняття рішення та межу виявлення в нормальному наближенні;
- довірчий інтервал для істинної нетто-швидкості лічби;
- перехід від швидкості лічби до активності та питомої активності;
- порівняння межі виявлення з регламентованим рівнем;
- оцінювання чистої площі гамма-піка за бічними фоновими ділянками;
- перевірку вхідних даних та автоматизовані тести.

Реалізація використовує лише стандартну бібліотеку Python.

## Огляд методики

Для фонових відліків `N0`, накопичених за час `t0`, і брутто-відліків `Nb`,
накопичених за час `tb`, нетто-швидкість лічби дорівнює:

```text
r_net = Nb / tb - N0 / t0
```

Активність визначається через відгук детектора:

```text
A = r_net / (efficiency * gamma_yield)
```

Для ROI піка кількість фонових відліків масштабується пропорційно до відношення
ширини пікового вікна до сумарної ширини фонових вікон. Дисперсії пуассонівських
відліків поширюються через операцію віднімання.

## Запуск прикладів

Потрібен Python 3.10 або новіший.

```bash
python -m radiometric_detection_limits.examples
python -m radiometric_detection_limits.examples --csv results/example_results.csv
```

Сторонні бібліотеки для виконання розрахунків не потрібні.

## Запуск тестів

```bash
python -m unittest discover -s tests -v
```

## Обмеження

У формулах використано нормальне наближення до пуассонівської статистики
лічби. Пороги для ROI є спрощеними навчальними оцінками. Програму не валідовано
для регуляторних, критичних для безпеки, медичних або дозиметричних рішень.
Реальна методика вимірювання має відповідати застосовному стандарту, процедурі
калібрування, бюджету невизначеності та моделі детектора.
